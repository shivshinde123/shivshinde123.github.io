# Ganeshotsav 2026

A static Ganeshotsav festival guide and photo gallery.

## Run locally

Open `site/index.html` in a browser, or serve the `site` directory with any static web server.

## Publish with GitHub Pages

The GitHub Actions workflow publishes the contents of `site/` to GitHub Pages whenever changes are pushed to the `main` branch.

After the first successful workflow run, the website will be available at:

https://shivendra123.github.io/
